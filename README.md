# Cattle Logbook phone

Public iPhone page for Cattle Logbook. Add it to the home screen from Safari. The herd book stays in the private repository.

https://gordon55-a11y.github.io/cattle-logbook-phone/

Sign in with the personal Microsoft account that owns the OneDrive folder. The phone reads and writes only `Cattle Logbook/phone-practice/cattle-logbook-data.json`. It does not open the live herd file.
