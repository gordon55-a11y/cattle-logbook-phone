# Cattle Logbook phone

Public iPhone page for Cattle Logbook. Add it to the home screen from Safari. The herd book stays in the private repository. This site ships with made-up sample animals only.

https://gordon55-a11y.github.io/cattle-logbook-phone/

The Microsoft application (client) ID in `js/config.mjs` is still a placeholder. Until that is a real ID, the phone keeps the sample book on the device and does not contact Microsoft or OneDrive.
