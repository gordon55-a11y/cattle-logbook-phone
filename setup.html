Set up the phone once

Do these steps once. After that, open the green Cattle icon. The phone reads and writes only the live herd file, the same book the computer uses.

1. A public page for the icon

The cattle program on the computer stays in the private repository. A free website cannot be published from that private repository. The phone page needs its own public repository, with no herd file in it.

  1. Sign in to GitHub as gordon55-a11y.
  2. Create a new repository named cattle-logbook-phone.
  3. Set it to Public. Leave it empty: no README, no licence file.
  4. Do not change the private cattle-logbook repository to public.
  5. Reply that the empty repository exists. The phone files can then be copied into it. Only the phone page goes in. Not the computer program.
  6. On that new repository: Settings, then Pages, then branch main and folder / (root). Save.
  7. Wait until this address opens: https://gordon55-a11y.github.io/cattle-logbook-phone/

2. Tell Microsoft about the phone page

Use the same Microsoft account that owns the OneDrive folder on the cattle computer. No password is stored in the page.

  1. Open https://entra.microsoft.com and sign in.
  2. Go to Identity, then Applications, then App registrations, then New registration.
  3. Name: Cattle Logbook Phone.
  4. Who can use it: Personal Microsoft accounts only.
  5. Redirect URI: choose platform Single-page application. Do not choose Web. Paste this address, including the slash at the end:
    https://gordon55-a11y.github.io/cattle-logbook-phone/
  6. Press Register.
  7. On the overview, copy the Application (client) ID. It looks like 12345678-1234-1234-1234-123456789abc. That is not a password. Do not create a client secret or a certificate.
  8. Open API permissions. Microsoft Graph, delegated, should already include User.Read. Add delegated Files.ReadWrite. Do not add anything with “All” in the name, and do not add an Application permission.
  9. Open Authentication. The single-page redirect above should be listed. Leave the boxes for Access tokens and ID tokens unticked.
  10. Send only that Application (client) ID. It is pasted into the phone page in place of PASTE-APPLICATION-CLIENT-ID-HERE.

The first time the phone signs in, Microsoft shows a warning that the publisher is unverified. That is normal for a private page like this. Accept only if the name is Cattle Logbook Phone. The wording talks about files in OneDrive, because Microsoft has no switch for one file. The page is written to open only Cattle Logbook/cattle-logbook-data.json.

Sign in with the personal Microsoft account that owns the OneDrive folder, not a work account from the new directory. The page uses the “common” sign-in address, because this registration allows both work accounts and personal accounts.

3. Put the icon on the iPhone

Use the iPhone 18 Pro. Open Safari, not another browser.

  1. Go to https://gordon55-a11y.github.io/cattle-logbook-phone/
  2. Tap Share (the square with the arrow).
  3. Tap Add to Home Screen.
  4. Name it Cattle. Tap Add.
  5. After that, open the green icon. The first open needs a signal, so the phone can fetch the page and sign in.

Notes go to the live herd file. The practice copy is not opened.

The home screen shows Live book next to the version number. To use the practice copy again, the page has to be published with the practice path instead.
